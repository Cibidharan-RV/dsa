## Idea

[View Submission on LeetCode](https://leetcode.com/problems/binary-search/submissions/2119446814)

Basic binary search.
Check if middle element is equal to the target. 
if mid element is greater, the target should be in left half. 
if mid element is smaller, the target should be in right half.
repeat this until the target is found.
