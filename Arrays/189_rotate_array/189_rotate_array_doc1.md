# 189. Rotate  Array

## Difficulty
Medium

## Topic
- Array

---

## Idea

Reverse the array from index 0 to n - k - 1
Reverse the array from index n - k to n - 1
Reverse the whole array

---

## Time Complexity

O(n)

## Space Complexity

O(1)

---

## Mistakes Made

- used copying and other conventional algorithm. until seeing the hint.
